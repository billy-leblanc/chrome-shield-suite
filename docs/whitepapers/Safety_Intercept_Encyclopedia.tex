\section{VOLUME I: FOUNDATIONS}\label{volume-i-foundations}

\subsection{I. The Executive Thesis}\label{i.-the-executive-thesis}

\subsubsection{The Intent Layer Category
Claim}\label{the-intent-layer-category-claim}

Safety Intercept operates natively at a completely new vector of
cybersecurity: \textbf{The Intent Layer}. Traditional fraud systems
operate at the Identity Layer (who is logging in) or the Transaction
Layer (where the money is going). Safety Intercept is the only platform
that answers the fundamental question: \emph{``Should this transaction
happen at all?''}

By intercepting the consumer inside the browser DOM at the exact
millisecond of payment authorization, Safety Intercept reads the
psychological intent behind the transfer, interceding before the API
calls even reach the bank.

\subsubsection{The ``Fraud is a Decision Problem''
Framework}\label{the-fraud-is-a-decision-problem-framework}

Fraud is rarely an unauthorized technical hack. Over 90\% of modern
cyber threats originate from social engineering. Fraud is fundamentally
a \emph{decision problem caused by emotional manipulation}. Legacy
models attempt to solve authorized push payment (APP) fraud using
mathematical velocity metrics. Safety Intercept treats it as a cognitive
issue---deploying a psychological circuit breaker to snap the victim out
of the ``scammer's trance.''

\subsubsection{Structural Failure of Transaction-Layer
Systems}\label{structural-failure-of-transaction-layer-systems}

Incumbents like Stripe Radar and Plaid Signal analyze the aerodynamics
of an airplane after the engine has failed. They rely on lagging
indicators: device biometrics, IP velocity, and historical transaction
volume. Because they lack upstream visibility into the consumer's inbox
(e.g., Gmail) and sit behind the API wall, they are mathematically
locked out of capturing the emotional context that drove the
transaction.

\subsubsection{Market Timing \& Regulatory
Shifts}\label{market-timing-regulatory-shifts}

The market is starved for this pre-transaction interception layer. 1.
\textbf{APP Fraud Statistics:} In 2025, Americans reported a
record-breaking \$15.9 billion in fraud losses. Imposter scams
leveraging P2P platforms like Zelle and PayPal represent billions of
these irrevocable transfers. 2. \textbf{Nacha 2026 Phase 2 Rules:}
Effective June 19, 2026, the Nacha Operating Rules mandate that all ACH
participants must establish risk-based fraud monitoring to identify
transactions authorized under false pretenses (e.g., Business Email
Compromise). 3. \textbf{CFPB Paradigm:} Liability shifts are forcing
networks (Zelle) to absorb scam losses, pivoting their financial
incentives from passive processing to active fraud blockage.

\subsubsection{Live Surfaces}\label{live-surfaces}

\paragraph{1. PayPal Interception}\label{paypal-interception}

The \texttt{payment\_interceptor.tsx} content script actively observes
the PayPal Single Page Application (SPA). Utilizing a
\texttt{MutationObserver} mapped to \texttt{.send-btn}, the script
deploys a click event listener configured with
\texttt{\{\ capture:\ true\ \}}. The moment the user clicks ``Send'',
the extension calls \texttt{event.stopImmediatePropagation()}, halting
the UI entirely. A proprietary modal falls into the viewport, forcing
the user through a Trance-Breaker Questionnaire analyzed by Claude Haiku
in real-time.

\paragraph{2. Wells Fargo Zelle
Interception}\label{wells-fargo-zelle-interception}

Fully hash-route aware. Because Zelle pathways inside Wells Fargo use
dynamic React routing rather than hard page loads, the system monitors
specific URL parameter shifts. Upon reaching the payment confirmation
node, the identical cross-layer interception protocol is executed.

\paragraph{3. Gmail Scam Detection}\label{gmail-scam-detection}

Operating asynchronously from the payment interceptor, the Gmail content
script evaluates inbound emails. It injects high-contrast warning
banners and visual ``flag pills'' directly into the DOM structure of
suspicious emails. It weights locally processed heuristics against
Claude API results (configurable to a 20/80 or 80/20 heuristic-to-LLM
confidence blend). It records the semantic signature of the scam.

\subsubsection{The Intelligence Stack}\label{the-intelligence-stack}

\paragraph{1. Heuristics}\label{heuristics}

The system utilizes 18 distinct regex baseline patterns to catch
zero-day and low-level fraud instantly. This circumvents API latency and
provides immediate scoring for well-known vectors (e.g., ``bail money'',
``IRS penalty'', ``\$500 refund overcharge'').

\paragraph{2. Claude Haiku Integration}\label{claude-haiku-integration}

If heuristics fall below a confidence threshold, the payload is parsed
and routed via a Cloudflare Worker relay
(\texttt{shield-relay.bleblanc.workers.dev}). The worker protects API
keys (\texttt{VITE\_RELAY\_AUTH\_TOKEN}) and proxies the semantic
payload to Anthropic's Claude 3 Haiku model. With an average round-trip
latency of \textasciitilde500ms, Haiku evaluates the psychological
pressure of the message and returns a standardized risk object.

\paragraph{3. Cross-Layer Correlation (The
Moat)}\label{cross-layer-correlation-the-moat}

This is the single most defensible technical asset within Safety
Intercept. * \textbf{Mechanism:} When the Gmail scanner flags a
high-risk email, it serializes a non-PII token representing the threat
signature and stores it in \texttt{chrome.storage.local} with a
timestamp. * \textbf{Activation:} The correlation engine checks this
local storage payload when a user hits a `Send' button on PayPal or
Zelle. * \textbf{The Math:} If a payment attempt occurs within a 24-hour
window of a flagged email, the system appends a \texttt{correlationNote}
to the payload and injects an automatic, unmitigable \textbf{+30 points}
to the transaction's overall risk score.

Intercept possesses the exact linguistic coercion utilized in the 17

neutrality and destroys trust with its B2B banking clients. Legacy
vendors are structurally trapped outside the consumer browser.

\subsection{Appendix A: Code Architecture
Reference}\label{appendix-a-code-architecture-reference}

The Safety Intercept architecture is fully dependent on Chrome
Extensions Manifest V3 (MV3) acting in tandem with edge compute services
to bypass the heavy requirements of local LLMs.

\subsubsection{Core File Structure}\label{core-file-structure}

Based on \texttt{claude\_knowledge\_base.txt}:

\begin{itemize}
\tightlist
\item
  \texttt{manifest.json}: Defines the MV3 permissions. Declares broad
  host permissions (\texttt{"*://*.paypal.com/*"},
  \texttt{"*://*.mail.google.com/*"}) required for DOM injection.
  Enforces \texttt{chrome.storage} for the correlation variables.
\item
  \texttt{content\_scripts/payment\_interceptor.tsx}: The primary
  execution node. Uses \texttt{MutationObvserver} to query the DOM
  asynchronously as React hydrates the page. Binds a
  \texttt{\{\ capture:\ true\ \}} click listener to the \texttt{Send} or
  \texttt{Pay} button.
\item
  \texttt{content\_scripts/gmail\_analyzer.tsx}: Executes asynchronously
  on \texttt{mail.google.com}. Parses email bodies for coercive
  semantics. Triggers warning banners using standard
  \texttt{document.createElement}, dropping visual warning pills at the
  top of the viewport.
\item
  \texttt{background/background.ts}: The MV3 Service Worker. Acts
  strictly as an ephemeral message router to circumvent the 30-second
  execution kill limit. Brokers the fetch requests between the content
  scripts and the Cloudflare worker.
\item
  \texttt{cloudflare/relay-worker.js}: The backend proxy hosted at
  \texttt{shield-relay.bleblanc.workers.dev}. Hardcodes the Anthropic
  API key (\texttt{ANTHROPIC\_API\_KEY}) and authenticates inbound
  extension traffic via a shared secret
  (\texttt{VITE\_RELAY\_AUTH\_TOKEN}). Exposes \texttt{/analyze\_intent}
  endpoint communicating exclusively with
  \texttt{claude-3-haiku-20240307}.
\item
  \texttt{risk\_engine.ts}: Contains the mathematical thresholds.
  Evaluates heuristics, invokes the LLM API call via the background
  script, factors in the 24-hour Cross-Layer Correlation score boost
  using
  \texttt{await\ chrome.storage.local.get({[}\textquotesingle{}threat\_token\textquotesingle{}{]})},
  and computes the final 0-100 \texttt{riskScore}.
\end{itemize}

\subsubsection{The End-to-End Data Flow}\label{the-end-to-end-data-flow}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Context Acquisition:} \texttt{gmail\_analyzer.tsx} identifies
  a threat → sets
  \texttt{chrome.storage.local.set(\{\ threat\_token:\ timestamp\ \})}.
\item
  \textbf{Execution Halt:} User attempts P2P transfer →
  \texttt{payment\_interceptor.tsx} captures the click, strips PII, and
  halts propagation.
\item
  \textbf{Transmission:} Content script emits
  \texttt{chrome.runtime.sendMessage()} to the Service Worker.
\item
  \textbf{Relay:} Service Worker authenticates against the Cloudflare
  Worker.
\item
  \textbf{Inference:} Cloudflare Worker queries Anthropic Claude Haiku
  with standard prompt engineering (``You are an expert fraud
  analyst\ldots{} return JSON.'').
\item
  \textbf{Result Assembly:} Cloudflare returns JSON payload to Service
  Worker.
\item
  \textbf{Score Calculation:} Service Worker feeds payload to
  \texttt{risk\_engine.ts}. The storage token adds +30 correlation.
\item
  \textbf{Intervention:} Final score routed back to
  \texttt{payment\_interceptor.tsx} → UI state updates to Drop Vault
  Door if specific thresholds are breached.
\end{enumerate}

\subsection{Appendix B: Glossary of
Terms}\label{appendix-b-glossary-of-terms}

\begin{itemize}
\tightlist
\item
  \textbf{Agentic AI Fraud Analyst:} Safety Intercept's operational
  identity. An LLM agent configured to autonomously interdict threats
  actively operating in the consumer's web environment.
\item
  \textbf{Authorized Push Payment (APP) Fraud:} A scam wherein a
  consumer is socially engineered into willingly transferring funds
  directly to a fraudulent counterparty using an instant payment
  network.
\item
  \textbf{Cross-Layer Correlation:} The proprietary mechanism of
  associating a hostile semantic flag in an inbox (e.g., Gmail) with a
  subsequent payment transfer at a discrete endpoint (e.g., PayPal),
  temporally linked within 24 hours.
\item
  \textbf{Decision-Layer Security:} The fundamental cybersecurity
  paradigm where the protective measure addresses the \emph{user's
  decision} to execute the action, as opposed to the \emph{network
  transmission} of the action.
\item
  \textbf{Intent Layer:} The cognitive environment bridging the
  consumer's psychological reason for initiating a transaction and their
  physical input.
\item
  \textbf{Margaret Scenario:} The archetype case study representing the
  core vulnerable demographic (aging seniors targeted by
  tech-support/refund scams).
\item
  \textbf{Psychological Circuit Breaker:} The user interface
  specifically designed to force a cognitive break, stopping the
  ``automatic'' behavior driven by scammer urgency.
\item
  \textbf{Trance-Breaker Questionnaire:} The real-time interactive modal
  dropped over a halted transaction that forces the victim to articulate
  \emph{why} they are sending the money, thereby breaking the social
  engineering momentum.
\end{itemize}
